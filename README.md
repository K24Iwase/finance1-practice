## 解法パターン早見表

| テーマ | 核心となる条件式 |
|--------|----------------|
| 競争均衡（私的財） | $D(p) = S(p)$ |
| 従量税の均衡 | $p^D - p^S = T$ |
| 従価税の均衡 | $p^D = (1+\tau)p^S$ |
| 弾力性と税転嫁 | 消費者転嫁率 $= \dfrac{\varepsilon^s}{\varepsilon^d + \varepsilon^s}$ |
| ラーナー独占度 | $L = \dfrac{p-MC}{p} = \dfrac{1}{\varepsilon}$ |
| 独占の最適条件 | $MR = MC$ |
| サムエルソン条件（公共財） | $\sum MV_i = MC$ |
| リンダール均衡 | 各人の $MV_i =$ 個人負担単価 |
| ピグー税 | $t^* = SMC - PMC$ （社会最適点で評価） |
| 労働所得税の死荷重 | $DWL \propto t^2$（税率2倍 → DWL4倍） |
