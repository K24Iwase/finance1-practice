## 解法パターン早見表

| テーマ | 核心となる条件式 |
|--------|----------------|
| 競争均衡 | $D(p) = S(p)$ |
| 従量税の均衡 | $p^D - p^S = T$ |
| 従価税の均衡（消費者課税） | $p^D = (1+\tau)p^S$ |
| 従価税の均衡（生産者課税） | $p^S = (1-\tau)p^D$ |
| 弾力性と税転嫁 | 消費者転嫁率 $= \dfrac{\varepsilon^s}{\varepsilon^d + \varepsilon^s}$ |
| 独占の最適条件 | $MR = MC$、$MR = a-2bx$（逆需要が $a-bx$ のとき） |
| ラーナー独占度 | $L = \dfrac{p-MC}{p} = \dfrac{1}{\varepsilon}$ |
| サムエルソン条件（公共財） | $\sum MV_i = MC$ |
| リンダール均衡 | $MV_i = $ 個人負担単価、かつ需要量一致 |
| ピグー税 | $t^* = SMC - PMC\big|_{x^*}$ |
| 労働所得税の死荷重 | $DWL \propto t^2$（税率2倍 → DWL **4倍**） |
| 社会的余剰 | $SS = CS + PS - \text{外部費用}$（外部性がある場合） |
